Add a New Medication

Leave Effective Date blank unless this medication is replacing another one mid-month (then set it to the switch day, and set the OLD medication's Termination Date to that same day).

Medication Administration Report

Generates and uploads the selected resident's Medication Administration Report PDF for this date range to Google Drive — a full calendar month also generates automatically for the previous month on the 3rd of every month. Start and end date must fall in the same month; for a partial month (e.g. a resident discharged mid-month), just narrow the range.
