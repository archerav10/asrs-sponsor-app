File Naming Guide

You can put documents straight into a person's Google Drive folder, without going through the dashboard. When the file is named this way, the dashboard records it for you.

1. The rule

Code_Date.pdf
  • Code is the document's code from the lists below. It goes first. Capital letters don't matter.
  • Date comes after an underscore _ (a space works too). It's required for training that renews (yearly or every 2 years). It can be left off for one-time items and Annual Planning.
  • Don't put the person's name in it. The folder already says who it's for.

3. What happens next

  1. The dashboard checks the folder whenever you open that person's screen, and checks everyone's folders every night (3:15 AM).
  2. A recognized file marks its item done. On the person's screen it's listed under Picked up from Drive, and the item shows the file name.
  3. A file it can't place is listed under Files in the Drive folder the app couldn't place, with the reason. Rename it in Drive and reopen the screen.

Good to know

  • Renewals: for a yearly (or 2-year) training item, a file with a newer date replaces the one on file and moves the next due date. An older file is left alone.
  • Already on file: a one-time item or an Annual Planning document that's already done is never changed by a second file.
  • Items that don't apply to the person's role (e.g. a Sponsor-only item in a DSP's folder) aren't recorded. They show in the couldn't-place list.
  • Files the app created itself, and training-module certificates (Module_…), are recognized and left alone.

6. Adding a new document type

Staff Training: you can do this yourself in Notion

  1. Open the Training Requirements database in Notion and add a row.
  2. Fill in Label (what it's called), Part, Section, Applies To (Sponsor, DSP, Secondary DSP), Renews (One-time, 1 year or 2 years) and Order, and check Active.
  3. Give it a Key. This is the code for file names: letters and numbers only, no spaces, e.g. FireSafety. Pick it carefully: never change a Key once it's used. To rename the item, change its Label instead.
  4. Reload the dashboard. The item appears on everyone it applies to, and its code appears on this page.

To retire an item, uncheck Active. Don't delete the row.

Annual Planning: ask Claude

The Annual Planning checklist is part of the app's code, and each document needs two new columns in the Resident Annual Planning database. Ask Claude to add it, giving the document's name and the code you'd like. The code shows up here once it's added.
